# 手动部署流程（命令行版）

> 适用场景：不想/不能用 bat 双击（远程桌面、公司服务器、给技术朋友部署、双击失败要排查）。
> 与 bat 自动版二选一即可，效果完全一样。所有命令在 **cmd** 中执行。

## 第 0 步 · 环境确认

```cmd
python --version
```
- 显示 `Python 3.10` 及以上 → 继续
- 报"不是内部或外部命令" → 重装 Python，安装时务必勾选 **Add Python to PATH**
- 装了但版本旧 → 用 `py -3 --version` 试一下，后文命令里的 `python` 都可换成 `py -3`

MySQL 确认（本机服务方式安装的）：

```cmd
sc query MySQL80
```
STATE 显示 `RUNNING` 即正常（服务名可能是 MySQL / MySQL80 / MySQL84，取决于安装版本）。

## 第 1 步 · 安装依赖

进入项目目录（假设项目在 `D:\juejin`，实际按你的路径改）：

```cmd
cd /d D:\juejin
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

装签到要用的浏览器内核（约 120MB，一次即可）：

```cmd
python -m playwright install chromium
```

## 第 2 步 · 建数据库

```cmd
mysql -u root -p
```
输入 MySQL 密码进入后执行：

```sql
CREATE DATABASE IF NOT EXISTS juejin DEFAULT CHARSET utf8mb4 COLLATE utf8mb4_general_ci;
EXIT;
```
> 报"mysql 不是内部或外部命令"：用 MySQL 安装目录的完整路径，例如
> `"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p`
> 表不用建——首次抓取时脚本自动建表。

## 第 3 步 · 写配置

```cmd
copy config.example.json config.json
notepad config.json
```

把 `"password": "在这里填你的MySQL密码"` 改成真实密码，保存关闭。

验证配置和连库（应输出 JSON 且密码显示为星号、能连库）：

```cmd
python jjconfig.py
```

## 第 4 步 · 保存掘金登录态（签到功能需要）

```cmd
python login_save.py
```
弹出浏览器 → 手动登录掘金（扫码即可）→ 检测到登录成功自动保存退出。
> 只抓沸点/评论不需要登录，游客也能抓；登录是为了签到、抽奖和更全的数据。

## 第 5 步 · 首次抓取 + 建表

```cmd
python auto_scrape.py --total 50 --comments 0
```
看到"已写入 MySQL 库 juejin: 沸点 xx 条"即成功（表已自动建好）。

## 第 6 步 · 启动看板

```cmd
python server\app.py
```
浏览器打开 http://127.0.0.1:5000 。
> 这个窗口要保持开着（Ctrl+C 即停止）。日常建议直接用 `一键启动看板.bat` 代替此步。

## 第 6.5 步（可选）· 签到 / 抽奖（命令行版）

签到、抽奖可分开跑，抽奖默认**只用免费次数、不花矿石**：

```cmd
python juejin_checkin.py --mode checkin            # 仅签到
python juejin_checkin.py --mode lottery            # 仅免费抽奖（无免费次数时直接跳过）
python juejin_checkin.py --mode all                # 签到 + 免费抽奖（默认）
python juejin_checkin.py --mode lottery --use-points --max-paid 3   # 免费用完后用矿石补抽, 最多3次(200矿石/次)
```

抓取节奏（并发/翻页间隔）也可用命令检查当前生效值——已从 `config.json` 读取，网页「高级设置」里改过就会生效。
> 这个窗口要保持开着（Ctrl+C 即停止）。日常建议直接用 `一键启动看板.bat` 代替此步。

## 第 7 步（可选）· 注册定时抓取计划任务

每 30 分钟自动抓一次（关掉看板也照常跑）：

```cmd
schtasks /create /tn "JuejinPinsScrape" /tr "D:\juejin\run_scrape.bat" /sc minute /mo 30 /f
```
> `/tr` 后面的路径按项目实际位置改；路径带空格要整体加引号。

查看/删除：

```cmd
schtasks /query /tn "JuejinPinsScrape"
schtasks /delete /tn "JuejinPinsScrape" /f
```

## 常见问题（手动版专属）

| 现象 | 原因与处理 |
|------|-----------|
| `pip` 装得极慢/超时 | 用第 1 步带的清华镜像参数；公司内网需配代理 |
| `playwright` 下载浏览器失败 | 重跑一次；或设置代理后重试 |
| `python login_save.py` 一闪而过 | 先去掉 `pause` 概念——在 cmd 里手动跑就能看到报错内容 |
| 脚本中文乱码 | 先执行 `chcp 65001` 再跑命令（脚本已自带 UTF-8 兼容，一般不会遇到） |
| 1045 密码错误 | 回到第 3 步核对 config.json；注意值两边不能有多余空格 |
| 计划任务显示"上次运行结果 0x1" | 日志在 `data\scrape_task.log`，打开看具体报错 |
| 抽奖提示"免费次数已用完" | 正常保护逻辑（不花矿石）；想继续抽见第 6.5 步的 `--use-points` 参数 |
| 抓太慢/被限流 | 网页「高级设置」调并发与间隔，或看 `config.json` 的 `scrape` 节 |
